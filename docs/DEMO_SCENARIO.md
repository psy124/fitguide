# FitGuide 5분 시연 순서

## 시연 전 운영자 준비
- [ ] 최신 ZIP 전체를 압축 해제하고 FitGuide.exe가 실행되는지 확인.
- [ ] 가상 데이터로 체험하기를 켜고 화면의 가상 데이터 표시 확인.
- [ ] 데모가 오래됐다면 데모 초기화 후 오늘 기준 기록 확인. 초기화하면 데모의 저장된 추천도 삭제됨.
- [ ] AI 추천에서 나의 식사 조건 저장, API 키 자동 실행 등록 및 서버 연결 확인.
- [ ] 가상 데이터로 AI 추천을 1회 생성해 추천 기록 저장 확인. 실제 발생한 응답만 사용.
- [ ] AI 재생성은 일일 횟수를 소비하므로 사용량과 인터넷 연결 확인.
- [ ] 발표 당일 화면 녹화 테스트. API 키/서버 비공개 설정 화면은 녹화하지 않음.

## 진행 (5분)
| 시간 | 동작 | 설명 |
|---|---|---|
| 0:00–0:30 | 홈, 가상 데이터 표시 | 기록·분석·AI 제안을 사용자가 실제 행동으로 연결하는 앱임을 소개 |
| 0:30–1:00 | 내 목표 | 목표/기구/부위가 추천의 입력 조건이라는 점 설명 |
| 1:00–1:40 | 운동 기록 | 종목 추가, 세트 완료 체크, 운동 종료. 완료한 세트만 기록됨 |
| 1:40–2:10 | 식사 기록 | 가상 음식의 섭취량과 기록된 영양 합계 확인. 합성 수치라고 명시 |
| 2:10–2:40 | 분석 | 운동 일수·부위별 세트·체중 추이 확인 |
| 2:40–3:30 | AI 추천 | 전송 동의와 후보 생성. 시간이 걸리면 저장된 추천 기록으로 전환 |
| 3:30–4:20 | 추천 기록 상세 | 운동 후보 추가 → 운동 초안, 식사 후보 추가 → 식사 계획 확인 |
| 4:20–4:45 | 기록 내역 | 기존 운동 기록 조회/수정 흐름 소개 |
| 4:45–5:00 | 마무리 | 로컬 저장, 기록/계획 분리, 외부 API와 검증 범위의 한계 설명 |

## 인터넷 또는 AI 장애 시
AI 오류 화면을 숨기거나 고정 결과를 새 AI 응답처럼 소개하지 않는다.
추천 기록에서 사전에 실제 생성해 저장한 결과를 열고 “저장된 AI 추천을 다시 조회하는 시연”이라고 명시한다.
저장된 결과가 없으면 기록·분석을 시연하고 AI 결과가 준비되지 않았음을 설명한다.
백업 영상은 실제 실행 녹화만 사용하고, 이번 작업에서는 아직 녹화하지 않았다.

## 발표에서 구분할 것
- 후보 추가 ≠ 운동 완료 / 음식 섭취.
- 허용 목록·알레르기 필터 검증 ≠ 건강 효과·안전성 검증.
- 자동화 테스트 성공 ≠ Gemini 응답 항상 성공.
- 현재 데모는 같은 운영자 PC에서 동작. 다른 기기의 AI 연결은 별도 HTTPS 구성이 필요.
