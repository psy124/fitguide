# 기능 명세 v0.1

## 범위

단일 사용자 로컬 웹앱. 헬스장 근력운동 초보~중급자를 대상으로 한다.
로그인, 사진 체형 분석, 음식 인식, 웨어러블, 챗봇, 알림, 의료적 식단 처방은 제외한다.

## 필수 기능과 완료 조건

1. 목표 설정: 목표, 전신 균형 또는 특정 부위 집중(1~2개), 경력, 주당 횟수, 회당 시간, 기구를 저장하고 다시 불러온다. focus 빈 배열은 전신 균형을 뜻하며 기존 부위 배열은 특정 부위 집중으로 해석한다.
2. 운동 기록: 날짜·종목·중량·횟수·세트를 입력/수정/삭제하고 이전 기록을 불러온다. 재실행 후에도 유지한다.
3. 대시보드: 주별 운동 일수, 부위별 세트, 종목별 중량·횟수, 선택적 체중 추이를 보여준다. 빈 기록도 처리한다.
4. 추천: 최근 28일 기록과 목표로 후보 최대 3개를 제공한다. 기구·제외 종목을 먼저 필터링한다. 후보 부족 시 이유를 표시한다.
5. 루틴 반영: 추천 수락으로 종목을 추가/교체하고 중복 적용을 막는다. 변경 전후를 보여준다.
6. 식사 가이드: 명시된 재료와 알레르기·선호·조리 여건으로 예시를 필터링한다. 적합한 후보가 없으면 없다고 표시한다.
7. 시연: 가상 데이터임을 표시한 4주 기록을 제공한다. 실제 기록을 조용히 덮어쓰지 않는다.

## 추천 설계

기구 및 사용자 제외 조건으로 후보 필터 → 목표 적합성·기록 분포·선호 점수 → 후보 정렬 → 설명 → 사용자 선택.
초기 가중치는 실험적 설정이며 문서화한다. 운동 시간은 추정임을 표시하고 실제 시간 보장을 하지 않는다.
기록이 없으면 시작용 추천을 제공한다. 운동량을 근육 성장이나 회복의 확정값으로 표현하지 않는다.
부위별 세트 집계는 우선 주동근 1개 기준으로 하여 중복 집계를 피하고 화면에 기준을 표시한다.

## 저장 데이터

프로필, 운동 종목, 운동 세션, 수행 세트, 루틴 및 항목, 체중 기록, 추천 및 피드백, 식사 선호.
샘플 데이터는 생성 규칙과 출처(합성)를 명시한다.

## 핵심 검증

- 준비된 입력의 주별/부위별 집계가 기대값과 일치한다.
- 목표 변경이 관련 후보 점수에 반영된다.
- 기구 미보유 및 제외 종목은 추천되지 않는다.
- 입력 오류, 빈 기록, 후보 부족이 앱 오류로 이어지지 않는다.
- 추천 수락과 기록 편집이 DB에 유지된다.
- 식사 예시의 명시된 알레르기 재료가 제외된다.
