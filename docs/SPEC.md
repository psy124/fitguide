# 현재 기능 명세 v2 — 2026-11-08

## 범위
단일 사용자 Windows 데스크톱 앱. 내부 UI 서버는 localhost에 바인딩하며 운영자 AI 서버를 통해 Gemini에 요청한다.
로그인/멀티유저 동기화, 이미지 분석, 음식 자동 인식, 웨어러블 연동, 의료적 처방은 지원하지 않는다.

## 화면과 완료 조건
1. 홈: 목표, 운동 일수, 누적 세트, 최근 기록 표시.
2. 내 목표: 목표·전신/특정 부위·경력·기구·일정·선택적 신체 정보 저장.
3. 운동 기록: 종목/세트 입력, 초안 유지, 루틴 저장/불러오기, 완료 세트만 실제 기록 저장.
4. 식사 기록: 영양 표시 기반 식품 등록, 실제 섭취 기록 CRUD와 합계, AI 식사 계획 조회/상태 변경.
5. 분석: 기간별 운동 빈도/부위별 세트/종목별 중량·횟수/체중 추이.
6. AI 추천: 새 추천 생성, 운동/식사 후보 추가, 추천 기록 조회/삭제.
7. 기록 내역: 날짜별 운동 그룹 조회, 개별 세트 수정/삭제.

## AI 추천
규칙 점수로 후보를 선택하지 않는다. 조건에 따른 허용 운동/재료 목록과 실제 기록 요약을 모델에 전달한다.
AI가 최대 운동 3개·식사 3개를 반환하고 앱이 1. 추천할 운동 / 2. 추천할 식사로 표시한다.
입력에 없는 종목/재료, 제한 조건과 충돌하는 후보, 잘못된 형식은 거절한다.
운동 추가는 기존 초안을 보존하며 미완료 세트로 추가한다. 식사 추가는 계획이며 섭취량 합계에 반영하지 않는다.
과거 후보 추가는 현재 조건으로 재검증한다. 추천 당시 입력 요약은 내부 보관하며 화면에는 노출하지 않는다.
전송 동의, 서버 인증, 한국 시간 일일 한도, 실패 횟수 차감, 중복 성공 요청 캐시를 적용한다.
생성 실패 시 규칙 추천을 AI 결과로 대신 보여주지 않는다. 기록 조회에는 API가 필요하지 않다.

API 키·시연 코드는 추천 이력에 저장하지 않는다.

## 데이터 해석 한계
운동 세트는 대표 부위 하나로 집계한다. 기록된 활동은 전체 활동을 의미하지 않는다.
식사 합계는 입력한 음식만 합산하며 필요 열량이나 결핍 판정이 아니다.
알레르기 검증은 등록된 성분 목록 범위이며 실제 제품 첨가물/교차접촉을 판별하지 않는다.
AI 추천은 의료적 효과나 안전을 보장하지 않으며 사용자가 검토해야 한다.
