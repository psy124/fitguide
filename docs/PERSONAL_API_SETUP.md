# 개인 Gemini API 설정 — 배포본 사용법

2026-11-14 개인 API 버전부터 **배포 앱에서 직접 API 키를 입력**할 수 있습니다.
Python 설치, 소스 다운로드, 접속 코드 발급, 별도 AI 서버와 터널 실행은 필요 없습니다.
앱이 본인의 Gemini API 키로 Google에 요청합니다. 인터넷 연결이 필요합니다.

## 다운로드와 실행

1. [배포 페이지](https://github.com/psy124/fitguide/releases/tag/v2026.11.14-personal-api)에서 FitGuide_Windows_PersonalAPI_2026-11-14.zip을 받습니다.
2. ZIP 전체를 압축 해제합니다.
3. FitGuide 폴더의 FitGuide.exe를 실행합니다. _internal 폴더를 함께 유지하세요.
4. Windows x64와 Microsoft Edge WebView2 Runtime이 필요합니다.

## 최초 설정

1. AI 추천 탭을 엽니다.
2. **내 Gemini API 설정**을 펼칩니다.
3. **Gemini API 키**에 본인의 API 키를 입력합니다.
4. **Gemini 모델 ID**에 본인 API 프로젝트에서 사용 가능한 gemini-로 시작하는 모델 ID를 입력합니다.
5. **하루 요청 한도**를 설정합니다. 기본 10회, 최대 1000회입니다.
6. **API 설정 저장**을 누릅니다.

설정 저장은 키와 모델의 실제 사용 가능 여부를 확인하는 호출이 아닙니다. 앱에서 추천을 생성해야 실제 연결을 확인할 수 있습니다.
특정 모델의 무료 이용을 보장하지 않습니다. Google API 사용량·비용은 본인의 프로젝트에 적용됩니다.

## AI 추천 생성

1. 시연이면 가상 데이터로 체험하기를 켭니다.
2. AI 추천에서 식사 조건과 운동 가능 시간·피로도·통증 여부를 확인합니다.
3. 기록 요약을 Google Gemini로 전송하는 데 동의합니다.
4. AI 추천 생성을 누릅니다.
5. 결과의 운동·식사 후보를 확인하여 추가합니다. 추천은 자동 저장됩니다.

식사 후보는 식사 기록 탭에서 수정·삭제할 수 있습니다. 후보 추가는 실제 운동 완료나 음식 섭취 기록과 별도입니다.

## 저장과 변경

- API 키는 현재 Windows 계정의 DPAPI로 암호화되어 %LOCALAPPDATA%\FitGuide\personal-ai.dpapi에 저장됩니다.
- 저장 후 키 입력란은 비워지며, 앱을 다시 실행해도 저장한 설정을 사용합니다.
- 모델·한도만 바꾸려면 키 입력란을 비운 채 저장하면 기존 키를 유지합니다.
- 키를 바꾸려면 새 키를 입력하고 저장합니다.
- 삭제 확인에 체크한 뒤 API 설정 삭제를 누르면 저장된 개인 API 설정만 제거합니다. 운동·식사·추천 기록과 사용량 DB는 유지합니다.
- 같은 Windows 계정 권한의 프로그램이나 관리자까지 키 접근을 차단하는 보호는 아닙니다.
- 다른 PC나 계정에서는 각자의 API 키를 다시 입력하세요.

## 기존 버전에서 업데이트

기존 앱을 종료하고 새 ZIP을 별도 폴더에 압축 해제하여 실행합니다.
같은 Windows 계정의 기존 기록은 유지됩니다. 새로운 개인 API 설정은 한 번 입력해야 합니다.
이 버전은 예전 ai-client.json, ai-autostart.json 또는 공유 AI 서버 설정을 AI 추천에 사용하지 않습니다.
이전에 수동 실행한 서버가 있다면 종료해도 됩니다. 새 앱이 기존 서버를 강제로 종료하지는 않습니다.
기존 암호화 키 파일은 자동으로 가져오거나 삭제하지 않습니다.

## 오류 해결

| 표시/증상 | 확인할 내용 |
|---|---|
| API 설정을 저장하라는 안내 | 내 Gemini API 설정에 키와 모델 ID 입력 |
| AI 추천 생성 버튼 비활성화 | 설정 저장과 전송 동의 확인 |
| 저장한 설정을 읽을 수 없음 | 해당 Windows 계정에서 키를 다시 입력하고 저장 |
| API_KEY_INVALID / PERMISSION | 키가 유효하고 해당 프로젝트에 모델 접근 권한이 있는지 확인 |
| MODEL_NOT_FOUND | API에서 사용할 수 있는 정확한 모델 ID 확인 |
| TIMEOUT / PROVIDER_UNAVAILABLE | Google 응답 지연·서비스 상태·인터넷 연결 확인 후 재시도 |
| 오늘 요청 한도를 사용 | 한국 시간 자정 후 재시도하거나 본인의 하루 한도 변경 |
| PROVIDER_QUOTA | Google 프로젝트의 API 한도·결제 설정 확인. 앱 한도와 별개 |

실패한 AI 호출도 로컬 일일 횟수에 차감될 수 있습니다. 키나 모델을 바꿔도 같은 PC의 오늘 사용량은 유지합니다.
앱이 종료되면 별도로 유지해야 할 AI 서버 창은 없습니다.

## 검증 범위

설정 암호화·저장·삭제·재실행, 모의 응답 기반 추천·한도, 기존 기능을 자동 검증합니다.
실제 Gemini 생성 성공 여부는 사용자가 입력한 키·모델·서비스 상태에 따라 달라집니다.
실제 키, 접속 정보, 개인 DB를 GitHub나 배포 ZIP에 올리지 마세요.
