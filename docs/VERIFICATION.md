이전 요청들에서는 503/시간 초과도 관측됐다. 성공률·평균 지연·일관성 비교 실험은 수행하지 않았다.

## 데스크톱/배포
Windows 실행 파일의 내부 서버 시작/종료 검증은 여러 갱신본에서 통과했다.
이번 제출 준비는 최신 clean-ai 빌드를 사용하며 패키지 내 사용자 DB/개인 키/운영자 설정 제외를 검사한다.
Python 미설치의 새 Windows 계정/다른 PC에서 이번 ZIP을 실행하는 최종 확인은 사용자가 수행해야 한다.
AI 자동 시작 키는 Windows 계정에 묶이므로 다른 PC로 복사해 사용할 수 없다.
