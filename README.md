# FitGuide

목표 체형과 운동 기록 기반의 설명 가능한 개인화 운동 추천 시스템.
컴퓨터공학 졸업작품 · 1인 개발 · 제출일 2026-11-12.

## 상태

2026-11-03: 요구사항과 개발 기록 체계 작성. 앱 구현 전이며 실행 가능한 앱은 아직 없습니다.
GitHub 저장소: https://github.com/psy124/fitguide
GitHub 접근 권한 확인 완료. 기능별 이슈 #1~#10을 등록했습니다.

## 구현 방향

- Python / Streamlit: 사용자 입력과 화면
- SQLite: 로컬 기록 저장
- pandas / Plotly: 집계와 그래프
- Python 규칙·점수 기반 추천: 근거를 설명하고 재현 가능한 추천
- pytest: 계산과 추천 제약 검증

## 개발 기록 원칙

기능별 GitHub 이슈를 만들고 관련 커밋에 이슈 번호를 기재합니다.
완료한 변경, 검증 결과, 남은 한계를 개발 일지에 기록합니다.
실제 수행한 작업만 기록하며 커밋 날짜를 소급하거나 진행률을 임의로 만들지 않습니다.
실제 사용자 DB, 비밀 키, 환경 파일은 저장소에서 제외합니다.

## 평가

목표 변경에 따른 추천 차이, 기구 제약 준수, 집계 정확성, 추천 적용 후 저장 여부를 검증합니다.
추천 결과는 기록 기반 제안이며 신체 변화나 의료적 효과를 입증하는 결과로 표현하지 않습니다.
