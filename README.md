# FitGuide

목표 체형과 운동 기록 기반의 설명 가능한 개인화 운동 추천 시스템.
컴퓨터공학 졸업작품 · 1인 개발 · 제출일 2026-11-12.

## 상태

2026-11-03: v0.1 구현. 홈 화면, 목표 저장·복원, 운동 세트 입력·조회가 가능합니다.
GitHub 저장소: https://github.com/psy124/fitguide
GitHub 접근 권한 확인 완료. 기능별 이슈 #1~#10을 등록했습니다.

## 구현 방향

- Python / Streamlit: 사용자 입력과 화면
- SQLite: 로컬 기록 저장
- pandas / Plotly: 집계와 그래프
- Python 규칙·점수 기반 추천: 근거를 설명하고 재현 가능한 추천
- pytest: 계산과 추천 제약 검증

## 실행 (Windows PowerShell / Python 3.13)

저장소 폴더에서 아래 명령을 실행하세요.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m streamlit run app.py
```

브라우저에서 http://localhost:8501 을 엽니다. 다음 실행부터는 `./run.ps1`도 사용할 수 있습니다.
종료하려면 실행한 터미널에서 Ctrl+C를 누르세요.

### 컴퓨터를 다시 켠 후

이 앱은 로컬 서버이므로 컴퓨터를 종료하면 서버도 종료됩니다.
프로젝트 폴더의 `start-fitguide.cmd`를 더블클릭하면 서버와 브라우저가 실행됩니다.
사용하는 동안 실행 창을 열어두세요. 서버 실행 후 http://localhost:8501 로 접속할 수 있습니다.
이미 서버가 실행 중이면 실행 파일을 다시 누르지 말고 해당 주소를 여세요.

## 테스트

```powershell
.\.venv\Scripts\python -m pytest -q
```

실제 기록은 `data/fitguide.db`에 저장되며 Git에서 제외됩니다.
테스트는 임시 DB만 사용합니다. `FITGUIDE_DB` 환경 변수로 저장 위치를 바꿀 수 있습니다.
단일 사용자 로컬 앱이므로 공개 서버에 사용자 데이터와 함께 배포하지 마세요.

## 현재 제한

화면 구성: ‘운동 기록’에서 운동 변경·입력·이전 기록 불러오기를 사용하고,
‘기록 내역’에서 날짜별 조회와 선택한 운동의 상세 수정·삭제를 사용합니다.
입력 화면에는 전체 기록 목록을 표시하지 않습니다.

- 같은 중량·횟수의 세트를 일괄 입력합니다. 다른 값은 별도로 입력합니다.
- 입력 저장 버튼을 다시 누르면 별도의 기록이 추가됩니다.
- 저장된 기록의 ‘기록 수정·삭제’에서 개별 세트를 편집하거나 확인 후 삭제할 수 있습니다.
- 종목 선택 후 ‘이전 기록 불러오기’에서 중량·횟수·세트를 입력칸에 복사할 수 있습니다. 저장 버튼을 눌러야 새 기록이 생성됩니다.
- 그래프·개인화 추천·식사 가이드는 아직 구현하지 않았습니다.
- 운동 종목 60개를 부위·기구·이름으로 검색할 수 있습니다.
- 현재 횟수 기반 기록만 지원하므로 플랭크·유산소 등 시간·거리 기반 종목은 제외했습니다.
