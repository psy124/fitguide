# FitGuide

목표 체형과 운동 기록 기반의 설명 가능한 개인화 운동 추천 시스템.
컴퓨터공학 졸업작품 · 1인 개발 · 제출일 2026-11-12.

## 상태

2026-11-04: 목표 설정, 루틴 기반 운동 기록, 기록 수정·삭제, 운동·신체 분석을 지원합니다.
GitHub 저장소: https://github.com/psy124/fitguide
GitHub 접근 권한 확인 완료. 기능별 이슈 #1~#10을 등록했습니다.

## 구현 방향

- Python / Streamlit: 사용자 입력과 화면
- SQLite: 로컬 기록 저장
- pandas / Streamlit 기본 차트: 집계와 그래프
- Python 규칙·점수 기반 추천: 근거를 설명하고 재현 가능한 추천
- pytest: 계산과 추천 제약 검증

## 실행 (Windows PowerShell / Python 3.13)

저장소 폴더에서 아래 명령을 실행하세요.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m streamlit run app.py
```

브라우저에서 http://localhost:8501 을 엽니다. 다음 실행부터는 `./run.ps1`도 사용할 수 있습니다.
종료하려면 실행한 터미널에서 Ctrl+C를 누르세요.

사용하는 동안 실행 창을 열어두세요. 서버 실행 후 http://localhost:8501 로 접속할 수 있습니다.

단일 사용자 로컬 앱이므로 공개 서버에 사용자 데이터와 함께 배포하지 마세요.

## 가상 데이터로 분석 체험

화면 상단의 **가상 데이터로 체험하기**를 켜면 데모 분석 화면으로 이동합니다.
실제 DB와 별도의 `data/fitguide.db.demo.sqlite3`에 저장하므로 실제 기록은 섞이지 않습니다.
데모에서는 목표 변경, 운동 입력, 기록 수정·삭제도 자유롭게 체험할 수 있습니다.

- 오늘 기준 최근 8주 범위: 운동 21일, 378세트, 6종목, 체중 16회와 예시 루틴.
- 분석 기간을 **전체**로 선택하여 주별 운동 일수·부위별 세트·중량 및 체중 변화 확인.
- 가상 중량은 2주마다 2.5kg 증가(크런치 0kg), 체중은 작은 등락을 포함합니다. 4번째 7일 구간은 운동을 쉬도록 생성합니다.
- 이는 합성 시연 데이터이며 실제 운동 성과나 건강 효과를 의미하지 않습니다.
- **가상 데이터 안내 · 초기화**에서 확인 후 초기화하면 오늘 기준 원본을 다시 생성합니다. 데모 수정·진행 중 운동은 지워지지만 실제 기록은 보존됩니다.
- 스위치를 끄면 내 기록으로 돌아갑니다. 두 모드는 목표·루틴·진행 중 운동도 분리됩니다.
- 날짜가 지나도 자동 재생성하지 않습니다. 필요할 때 초기화하세요. 생성된 DB는 Git에 올리지 않습니다.

## 현재 제한

‘운동 기록’은 오늘 운동 단위로 입력하고, ‘기록 내역’에서 날짜별 조회·수정·삭제합니다.

1. 빈 운동 또는 저장한 루틴을 선택하고 **운동 시작**을 누릅니다.
2. **+ 운동 추가**에서 부위·기구·이름으로 검색하여 여러 종목을 추가합니다.
3. 각 세트의 중량·횟수를 입력하고 실제 수행한 세트의 **완료**를 체크합니다.
4. 필요하면 현재 구성을 이름을 붙여 **루틴 저장**합니다. 완료 여부는 루틴에 포함하지 않습니다.
5. **운동 종료 · 완료 세트 저장**으로 완료한 세트만 기록에 반영합니다.

- 입력값은 입력 확정(Enter 또는 입력칸에서 포커스 이동) 시 SQLite에 자동 임시 저장됩니다. 새로고침·재접속 후 이어서 입력할 수 있습니다.
- 진행 중 운동은 단일 사용자당 하나입니다. 여러 브라우저에서 동시 편집하는 방식은 지원하지 않습니다.
- 운동 종료는 트랜잭션으로 처리하여 같은 운동을 두 번 저장하지 않습니다. 미완료 세트는 종료 시 버립니다.
- 종목당 최대 30세트이며 세트마다 다른 중량·횟수를 입력할 수 있습니다. 최근 운동일 기록을 기본값으로 불러옵니다.
- 기존 기록과 분석 데이터는 유지됩니다. 저장된 세트는 ‘기록 내역’에서 수정·삭제합니다.
- 루틴 이름은 중복할 수 없습니다. 루틴 수정은 불러온 뒤 구성을 바꾸고 새 이름으로 저장합니다. 시작 화면에서 기존 루틴을 삭제할 수 있습니다.
- 분석 탭: 최근 4주·12주·전체·직접 선택 기간의 주별 운동 일수, 부위별 세트 수, 종목별 최대 기록 중량과 총 반복 횟수, 선택적 체중 추이를 제공합니다.
- 규칙 기반 운동 추천을 제공합니다. 식사 가이드에서 재료·선호·조리 조건에 맞는 예시를 제공합니다.
- 운동 종목 60개를 부위·기구·이름으로 검색할 수 있습니다.
- 현재 횟수 기반 기록만 지원하므로 플랭크·유산소 등 시간·거리 기반 종목은 제외했습니다.

## 설명 가능한 운동 추천

**운동 추천** 탭에서 최근 28일 기록과 내 목표를 기준으로 최대 3개 후보를 확인합니다.
사용 가능한 기구에 해당하는 운동만 남기고, 저장한 제외 종목과 진행 중 운동의 중복 종목을 제거합니다.
각 카드에서 추천 이유를 확인한 뒤 **오늘 운동에 추가**를 누르면 진행 중 운동에 미완료 세트로 추가됩니다.
진행 중 운동이 없으면 오늘 날짜로 생성합니다. 기존 운동이 과거 날짜라면 화면에 표시된 날짜를 확인하세요.
기존 기록이 있으면 최근 운동일 값을 복사하고, 없으면 조정 가능한 0kg·10회·1세트 입력 시작값을 넣습니다.
이는 운동 처방이 아니며 완료 체크와 운동 종료 전에는 수행 기록으로 저장하지 않습니다.

추천은 실험적 점수 규칙입니다. 목표별 (강조 부위, 기록 분포, 익숙한 종목) 가중치는
근육 증가 (6,3,1), 체지방 감소 (3,6,1), 유지 (3,3,4)입니다.
기록 분포는 가장 많이 기록한 부위 대비 세트 수 차이를 0~1로 환산합니다.
서로 다른 대표 부위를 먼저 제안하며, 동점은 이름순으로 결정합니다.
이 설정은 제품의 정렬 정책이며 효과가 검증된 운동 지침이 아닙니다.
기록이 없는 경우 기구와 강조 부위로 후보를 제안합니다. 키·체중·BMI와 회복 상태는 점수에 사용하지 않습니다.
운동 수준·주당 횟수·회당 시간에 따른 전체 루틴 최적화, 자동 종목 교체는 아직 지원하지 않습니다.

## 식사 가이드

**식사 가이드 → 나의 식사 조건**에서 피할 알레르기 성분, 추가 제외 재료, 식사 선호,
준비 가능한 시간, 조리기구를 저장하면 조건을 모두 만족하는 예시를 보여줍니다.
재료·선택 이유·준비 방법과 제외된 예시의 이유를 확인할 수 있습니다.
조건은 재접속 후에도 유지되며 데모 모드와 실제 프로필에 각각 저장됩니다.

- 직접 구성한 예시 8종. 열량·영양소 계산이나 목표별 식단 처방은 제공하지 않습니다.
- 조리 시간은 준비된 밥·익힌 재료를 사용한 예상치입니다. 조리기구를 비우면 가열 없는 예시만 표시합니다.
- 모든 조건을 만족하는 후보가 없으면 없다고 표시하며 알레르기 필터를 자동 완화하지 않습니다.
- 등록된 재료와 알레르기 태그만 비교합니다. 모든 알레르기, 제품 첨가물, 교차접촉을 판별하지 않습니다.
- 통밀빵은 제품별 조성 차이를 고려하여 밀·우유·달걀·대두로 보수적으로 표시했습니다. 실제 제품 표시를 확인하세요.
- 원재료/알레르기 표시 및 교차접촉 안내 출처: [FDA Food Allergies](https://www.fda.gov/food/nutrition-food-labeling-and-critical-foods/food-allergies).
